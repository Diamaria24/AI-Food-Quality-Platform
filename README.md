# 🍎 AI Food Quality Platform

An AI-powered platform for food quality assessment using **RGB image analysis** and **hyperspectral imaging** for freshness estimation, spoilage assessment, and early mold detection.

---

## 📖 Project Overview

This project aims to develop a modular AI platform capable of analyzing food quality using two independent analysis pipelines:

- **RGB Image Analysis**
  - Food Identification
  - Healthy / Defective Classification
  - Freshness Estimation
  - Shelf-life Prediction
  - Storage Recommendations

- **Hyperspectral Analysis**
  - Spectral Data Processing
  - PCA-based Dimensionality Reduction
  - Early Mold Detection
  - Spectral Visualization
  - Confidence Score

The architecture is designed to support future integration with low-cost spectral sensors such as the **AS7341**.
